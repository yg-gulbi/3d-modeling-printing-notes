# Intelligent Robot

## Contents

| Folder | Content |
| --- | --- |
| `assemblies/` | combined intelligent robot assembly |

## What This Captures

- 로봇 몸체와 의자형 구조를 오가며 만든 형태 실험
- Arduino Mega case, sensor case, support pieces 같은 부품 분리
- assembly 캡처를 통해 전체 비례와 방향을 확인한 기록
