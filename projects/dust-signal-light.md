# Dust Signal Light

미세먼지신호등 모델은 기계설계2 과제 흐름 안에서 진행한 제품형 구조 설계 기록입니다. 문제의 핵심은 내부 공간이 부족해서 작업자의 배선/조립/수리 시간이 늘어난다는 점이었습니다.

## Model Groups

| Group | Where |
| --- | --- |
| Source CAD | `models/source-cad/SLDPRT/미세먼지신호등` |
| Assemblies | `models/assemblies/assemble/미세먼지*` |

## What This Captures

- 내부 공간을 남기는 케이스형 구조
- 열리는 문, 기둥, 밑판, 컨트롤판 같은 기능별 파트 분리
- assembly에서 내부 공간과 조립 관계를 확인한 흐름
- 단순 배선 정리보다, 옆 LED 판을 빠르게 탈착할 수 있게 만드는 접근
- push latch / push-lock 장비의 작동 원리를 참고해서 과제 상황에 맞게 바꾼 구조

## Design Idea

다른 사람들은 내부 선을 정리해서 작업 시간을 줄이는 쪽을 생각했지만, 이 설계에서는 작업자가 자주 접근해야 하는 LED 판 자체를 쉽게 떼고 다시 붙일 수 있게 만드는 쪽에 초점을 뒀습니다.

그래서 `솔루션1`, `솔루션2`, `내부기둥45도버전`은 내부 공간과 접근성을 개선하기 위한 구조 실험으로 봅니다. 정확한 세부 차이는 아직 추가 정리가 필요하지만, 큰 방향은 “작업자가 빠르게 열고 닫을 수 있는 미세먼지 신호등 구조”입니다.
