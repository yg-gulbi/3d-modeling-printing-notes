# Dust Signal Light

미세먼지신호등 모델은 기계설계2 과제 흐름 안에서 진행한 제품형 구조 설계 기록입니다. 여기서 `미세먼지신호등`, `미세먼지`, `솔루션1`, `솔루션2`, `내부기둥45도버전`은 서로 독립된 프로젝트가 아니라, 같은 신호등 구조 안에서 작업성과 내부 공간을 개선해 보려던 연속 실험으로 봅니다.

기준이 되는 일반 `미세먼지신호등`은 실제 모형에 가까운 기본안입니다. 문제의 핵심은 내부 공간이 부족해서 작업자의 배선/조립/수리 시간이 늘어난다는 점이었습니다.

## What This Captures

- 실제 모형에 가까운 기본 신호등 구조
- 내부 공간을 더 확보하려고 안쪽 판과 내부 배치를 바꿔 본 실험
- 열리는 문, 기둥, 밑판, 컨트롤판 같은 기능별 파트 분리
- assembly에서 내부 공간과 조립 관계를 확인한 흐름
- 단순 배선 정리보다, 옆 LED 판을 빠르게 탈착할 수 있게 만드는 접근
- push latch / push-lock 장비의 작동 원리를 참고해서 과제 상황에 맞게 바꾼 구조

## Design Idea

다른 사람들은 내부 선을 정리해서 작업 시간을 줄이는 쪽을 생각했지만, 이 설계에서는 작업자가 자주 접근해야 하는 LED 판 자체를 쉽게 떼고 다시 붙일 수 있게 만드는 쪽에 초점을 뒀습니다.

`미세먼지` 폴더 계열은 기존 신호등 자체 안에서 해법을 찾으려던 흐름으로, 안쪽 판의 형태를 바꿔 내부 공간을 넓히려는 실험으로 이해할 수 있습니다. `내부기둥45도버전`은 판이나 내부 부품의 접근성을 높이기 위해 내부 판을 45도로 돌려 보면 더 쉽게 작업할 수 있지 않을까 해서 만든 버전이지만, 결과적으로는 효율이 떨어졌고 기존 구조에도 적용하기 어려웠던 안으로 정리합니다.

`솔루션1`과 `솔루션2`는 push-latch 또는 push-lock 느낌의 구조를 만들려던 후속 실험입니다. `솔루션1`은 형태가 너무 흐물흐물한 느낌이 있어서 강성과 사용감을 보완하는 쪽으로 `솔루션2`로 넘어간 흐름으로 기록합니다.

## Preview Status

현재 이 프로젝트는 저장소에 STL export보다 SLDPRT/SLDASM 중심으로 남아 있어 자동 미리보기 이미지를 뽑지 않았습니다. 나중에 STL이나 스크린샷이 생기면 `images/model-previews/`에 추가하면 됩니다. 다만 문서상에서는 개별 폴더를 독립 프로젝트처럼 나누지 않고, 하나의 미세먼지 신호등 개선 흐름 안에서 읽히도록 유지합니다.
