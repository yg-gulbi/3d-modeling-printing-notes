# Lab Print Practice

이 문서는 연구실 3D 프린팅 실습과 실패/개선 관찰을 이력서용으로 정리한 노트입니다.

## What I Practiced

- STL 파일 확인과 출력 가능성 검토
- 출력 방향, 지지대 필요성, 벽 두께 감각 익히기
- 조립 부품에서 공차와 체결부가 실제로 어떻게 달라지는지 관찰
- 외부 다운로드 모델과 직접 설계 모델을 구분해서 관리

## Failure / Iteration Patterns

| Pattern | What I changed or checked |
| --- | --- |
| Thin or fragile tabs | 벽 두께와 체결부 주변 보강을 먼저 확인 |
| Poor fit after printing | 구멍, 보드 고정부, 케이블 통과부에 여유 공간 필요 |
| Support-heavy shapes | 출력 방향을 바꾸거나 부품을 분할 |
| Hard-to-service assembly | 덮개/플레이트를 다시 열 수 있는 구조로 변경 |

## Public Portfolio Policy

외부 다운로드 모델은 출력 연습에는 도움이 되었지만, 직접 제작 산출물처럼 보이지 않도록 이 저장소에는 원본 모델을 넣지 않았습니다. 직접 만든 로봇 부품과 공개 가능한 export만 포함했습니다.
