# Version and Iteration Notes

파일명에 `ver`, `vr`, `solution`, `실험`, `보수`, `scale`, `square` 같은 흔적이 많습니다. 아래 내용은 두 종류로 나눕니다. 사용자가 직접 설명한 내용은 그대로 정리하고, 세부 기록이 없는 부분은 파일명과 수정 시간 흐름을 기준으로 한 추정으로 표시합니다.

## Questions To Fill

각 프로젝트별로 아래 질문에 답하면 버전 정리가 자연스럽게 채워집니다.

| Question | Answer |
| --- | --- |
| 처음 목표는 무엇이었나? | 모델/과제마다 다름. 아래 섹션에 분리해서 기록 |
| 어떤 문제가 생겨서 버전을 나눴나? | 내부 공간, 조립 접근성, 출력/공차, 부품 분할, 후반 버전 개선 |
| 최종적으로 가장 괜찮았던 버전은 무엇인가? | 아직 일부 미확정. 파일 수정 시간이 늦은 버전을 후반안으로 우선 기록 |
| 출력/조립/공차에서 배운 점은 무엇인가? | 접근 가능한 구조와 출력 가능한 분할이 중요함 |
| 버려진 버전도 남겨둘 이유가 있나? | 실패/수정 흐름을 보여주므로 학습 기록으로 보존 |
