# Publication Policy

이 저장소는 public GitHub 포트폴리오를 기준으로 정리했습니다.

## Included

- 직접 설계한 밸런싱 로봇 관련 STL/STP export 일부
- 공개해도 무리가 없는 캡처 이미지와 조립 과정 이미지
- 설계, 출력, 개선 과정에 대한 학습노트

## Excluded

- 원본 대용량 영상
- 연구실 내부 맥락이 과도하게 드러나는 자료
- 외부 다운로드 모델 원본
- 출처와 라이선스가 애매한 CAD 파일
- 네이티브 CAD 전체 세트

## Reuse

이 저장소의 자료는 포트폴리오 검토를 위한 공개 자료입니다. 제조용 공식 도면이나 재배포 가능한 CAD 라이브러리로 제공하는 것은 아닙니다.
