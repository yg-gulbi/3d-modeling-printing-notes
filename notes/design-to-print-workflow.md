# Design-to-Print Workflow

## 1. Define the Mechanical Job

- 어떤 부품을 고정하는가
- 충격, 진동, 케이블, 열, 탈착 요구가 있는가
- 실제 조립 순서에서 접근 가능한가

## 2. Model for Assembly

- 보드/센서/배터리의 기준 위치를 먼저 잡습니다.
- 체결부, 케이블 통로, 유지보수 공간을 형상보다 먼저 확인합니다.
- 로봇처럼 넘어질 수 있는 장치에서는 보호 구조를 제어 안전 한계와 함께 봅니다.

## 3. Export for Printing

- STL은 출력용, STEP/STP는 교환/검토용으로 분리합니다.
- 공개 저장소에는 검증된 export만 넣고, 원본 네이티브 CAD는 필요할 때만 별도 관리합니다.

## 4. Inspect the Printed Part

- 체결부 파손 여부
- 케이블 간섭
- 센서 방향과 시야
- 보드 탈착 가능성
- 실제 로봇에서 진동/충격을 받았을 때의 고정성

## 5. Record the Lesson

출력 실패를 지우지 않고, 왜 실패했는지와 다음 수정 기준을 남깁니다. 완성 파일만 남기는 것보다 이 개선 과정을 같이 남기는 편이 나중에 다시 공부하거나 설명할 때 훨씬 도움이 됩니다.
